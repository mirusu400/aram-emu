# ARAM v0.6.0

LG PXO1 게임을 제품 실행 경로에 연결하고 SKT GNEX/GVM, KTF WIPI/Clet,
LGT Raptor·J2ME와 BREW 게임의 실행 범위를 넓혔습니다. 게스트의 텍스트 입력과
브라우저·전화·문자 요청을 호스트에 안전하게 전달하고, SMAF 오디오 재현과
실행 성능도 개선했습니다.

## 게임 호환성

- LG PXO1 패키지를 데스크톱·Android·libretro 실행 경로에서 인식합니다.
- SKT GNEX/GVM 검증 대상을 12개 늘리고 화면, 방향키, 타이머, 저장 데이터,
  오디오와 네트워크 처리를 보강했습니다.
- KTF WIPI/Clet의 타이머, 입력 이벤트, Java 런타임과 오프라인 인증 경로를
  개선했습니다.
- LGT Raptor/Clet 게임이 기기 해상도 전체를 사용하도록 화면 좌표 처리를
  일반화하고, J2ME 및 BREW/EADS의 화면·문자열·입력·콜백 처리를 개선했습니다.
- 시스템 모드 펌웨어로 전환할 때 CPU 상태가 어긋날 수 있는 문제를 수정했습니다.

호환성 검증은 확인된 게임 파일과 기기 프로필에 한정되며, 특정 형식 전체의
호환성을 의미하지 않습니다.

## 입력 및 플랫폼 연동

- Android에서 게임의 텍스트 필드에 네이티브 입력 창을 연결했습니다.
- 게임이 요청한 브라우저 열기·전화·문자 동작을 사용자 확인 후 운영체제에
  전달합니다.
- 모바일 빠른 동작을 네이티브 호스트 이벤트로 연결하고 터치 조작 오버레이를
  기본적으로 숨기도록 변경했습니다.

## 오디오 및 성능

- Yamaha SMAF MA-1·MA-2·MA-3·MA-5의 FM 음색, 드럼 뱅크, 모듈레이션,
  피치 벤드와 음량 처리를 개선했습니다.
- 오디오 큐의 대기·리샘플링 비용과 KTF 화면 갱신·가비지 컬렉션 비용을
  줄였습니다.
- ARM/Thumb 인터프리터의 반복 메모리 접근과 반환 경로를 최적화했습니다.
